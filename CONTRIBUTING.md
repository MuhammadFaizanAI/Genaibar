# Contributing to Genaibar

Contributions are highly welcome! Whether it's reporting a bug, suggesting a new feature, or improving documentation, your help makes this project better.

## How to Contribute

### Reporting Bugs
If you find a bug, please check the [Issues](https://github.com/MuhammadFaizanAI/Genaibar/issues) tab to see if it has already been reported. If not, please open a new issue with:
- A clear description of the issue.
- Steps to reproduce the bug.
- Any relevant screenshots or error messages.

### Suggesting Enhancements
If you have an idea for a new feature, please open an issue with the "enhancement" label. Describe the feature and why it would be beneficial.

### Pull Requests
1. **Fork** the repository.
2. **Create a branch** for your feature or fix (`git checkout -b feature/name` or `fix/name`).
3. **Make your changes**.
4. **Test your changes** to ensure they work as expected.
5. **Commit your changes** with a descriptive message.
6. **Push** your changes to your forked repository.
7. **Submit a Pull Request** to the main repository.

Please ensure your code follows the project's coding style and conventions.
