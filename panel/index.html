🚀 Quick Start & Features

Genaibar is built for maximum AI productivity. Master these features to speed up your workflow:

  • Instant Switch: Click any AI tab at the top to jump between configured assistants without losing state.
  • Full Capture (Alt+Shift+S): Instantly screenshot your entire current tab and upload it to the active AI.
  • Precision Crop (Alt+Shift+R): Select exactly what you need by dragging a region over the page.
  • Smart Copy (Alt+Shift+C): Highlight any text on the web to context-inject it directly into your AI chat.
  • Prompt Library: Click the document icon to access your saved prompt templates for 1-click entries.
  • Smart History: Access your last 40 screenshots and text snippets in the history panel for instant reuse.

FAQs

Why does "Auto-paste" fail sometimes?

AI sites like Claude or Gemini use advanced security that blocks "fake" pastes. Genaibar uses a Hidden File Input strategy to bypass this, but if it fails, the image is already on your clipboard—just press Ctrl+V.

Can I use this on PDF pages?

Yes, but with limits. Standard Chrome security blocks text selection on PDFs. Use the Screenshot Tool to capture PDF content visually.

Common Errors

"Chat input not found" Reason: The site changed its layout or is still loading. Fix: Wait 1 sec and try again, or click the chat box manually and paste.
"Content Script Blocked" Reason: Some system pages (like chrome://) block all extensions. Fix: Use Genaibar on standard websites only.
